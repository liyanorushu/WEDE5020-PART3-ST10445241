Welcome to the official web repository for **Sip & Sack Co.**, a South African lifestyle and custom merchandise brand based in Motherwell, Gqeberha (Port Elizabeth), Eastern Cape[cite: 1, 2]. 

This website provides an interactive e-commerce platform where customers, students, event planners, and local businesses can browse custom lifestyle merchandise, submit product inquiries, and get in touch for bulk corporate orders[cite: 2, 4, 5].

---

## Project Overview

Founded in 2024, **Sip & Sack Co.** specializes in personalizing everyday items to allow individuals and corporate clients to showcase their unique identity.

### Key Features
* **Product Catalog:** Showcases custom insulated stainless-steel tumblers, travel mugs, reusable cold cups, canvas tote bags, and enamel pin badges[cite: 1, 3].
* **Product Customization Inquiries:** Interactive form allowing users to input personalized text, select quantities, upload design logos, and request price quotes.
* **Responsive Layout:** Mobile-friendly design built with flexible grid layouts, CSS custom properties (variables), and unified color palettes[cite: 1, 2].
* **Contact & Location:** Integrated Google Map for office location in Motherwell, Eastern Cape, operating hours, and customer support channels.
